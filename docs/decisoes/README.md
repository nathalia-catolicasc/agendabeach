# Registro de decisões de arquitetura e processo (ADR)

Cada decisão que altera o acordo de engenharia, a arquitetura ou o processo da equipe é registrada aqui
antes de entrar em vigor. Uma ADR aceita não é editada: se a decisão mudar, cria-se uma nova ADR que a
substitui.

| ADR                                                    | Título                               | Status | Data       |
| ------------------------------------------------------ | ------------------------------------ | ------ | ---------- |
| [ADR-001](ADR-001-convencao-de-commits-e-branches.md)  | Convenção de commits e de branches   | Aceito | 27/11/2026 |

## Modelo

```markdown
# ADR-NNN – Título

| Campo     | Valor |
| --------- | ----- |
| Status    | Proposto / Aceito / Substituído por ADR-XXX |
| Data      | dd/mm/aaaa |
| Decisor   | |
| Ratificam | |

## Contexto
## Decisão
## Consequências
## Alternativas consideradas
```
